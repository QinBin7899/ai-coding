## Screenshot Rules

- Use real AI Coding screenshots from the current build.
- Use AI Coding names, logos, guides, and interface captures only.
- Avoid screenshots containing private API keys, tokens, email addresses, or personal access credentials.
- Prefer dark mode screenshots because AI Coding defaults to a dark charcoal theme.
- Keep the orange accent visible where possible.
