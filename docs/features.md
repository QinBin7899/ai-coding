# AI Coding Feature Overview

AI Coding is designed for developers who use more than one AI coding tool and more than one model provider.

## Provider And Model Switching

- Manage API providers for Claude Code, Claude Desktop, Codex, Gemini CLI, OpenCode, OpenClaw, Hermes, and Bincode.
- Add providers from organized domestic and overseas preset groups.
- Keep custom providers in a separate configuration area.
- Switch API endpoint, API key, model name, and routing behavior from the desktop UI.
- Use local routing when a tool needs protocol conversion or proxy takeover.

## Bincode Integration

Bincode is included as a first-class app in the switcher and uses the OpenCode-compatible configuration flow. This lets Bincode share provider management, model switching, and related workspace configuration with the rest of the AI Coding ecosystem.

## Memory Sync

The cross-tool memory sync panel reads Claude Code memory and pushes it into supported tools such as Codex CLI, Gemini CLI, Hermes Agent, OpenCode, and OpenClaw. The goal is simple: define important project knowledge once, then reuse it across the coding agents you actually work with.

## Sessions

The session manager helps users review previous AI coding conversations. It supports:

- Local session discovery.
- Session list browsing.
- Conversation detail view.
- Resume command display.
- One-click Markdown export.

## Skills, MCP, Prompts, And Agents

AI Coding centralizes the parts of AI tooling that usually live in different folders:

- MCP server configuration.
- Prompt templates.
- Skills import, export, and storage settings.
- Agent defaults.
- Workspace-related configuration.

## Interface

The visual style is intentionally different from a plain settings app:

- Warm orange primary color inspired by Claude.
- Dark charcoal default theme.
- Translucent glass panels.
- Rounded macOS-style controls.
- Floating Dock navigation with dynamic hover magnification.
