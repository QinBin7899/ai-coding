# AI Coding v3.22.0

> 发布说明：源码范围已确认，最终前端验证和桌面安装包状态见文末。

本版修复会话搜索的放大镜与精准/模糊模式交互，并在 AI Coding 3.21.0 定制基础上选择性补齐 CC Switch 的兼容修复及新增供应商预设。

## 会话搜索

- 搜索标题、摘要、项目目录、会话标识和聊天正文；支持精准短语与模糊匹配，保存上次使用的模式。
- 修复打开搜索时因焦点变化而立即关闭的问题，切换匹配模式时保持搜索区域可操作；支持 X / Escape 明确关闭。
- 显示正文检索进度及错误；消除旧的 200 会话截断。

## 上游增量

原固定范围为 CC Switch `v3.20.1..38cfafdc199604b132be5eafe3f5384d85124a81` 的 32 个提交。新增腾讯 Token Plan、QwenCloud、AICodeWith、9527CODE 的对应应用预设和图标，补齐 xAI/Grok 原生 Responses、Moonshot/Kimi schema、Codex OAuth、会话恢复统计、模型目录、定价、Hermes 版本探测及控件可访问名称。

32 项均按本地定制逐项处置，其中 Grok 4.5 保留本地 low/medium/high 三档策略，没有采用上游 xhigh 声明。功能来自增量移植，不代表全部行为与上游一致。

2026-09-08 已在线核查 [CC Switch v3.20.2](https://github.com/farion1231/cc-switch/releases/tag/v3.20.2)。在原范围之外，额外吸收八项变更：

- Pi 新增 Tencent TokenHub / Token Plan、PPIO，补齐模型目录；预设移除已除名的 Tencent minimax-m2.5，不改用户已有供应商卡。
- 修正 PPIO、JieKou、Novita 的 Claude 模型发现地址。
- 修复代理日志处理多字节 URL 时的崩溃，排除误入会话列表的 workflow journal.jsonl。
- 隔离 Windows 集成测试的 Claude Desktop 配置路径；补齐已有 Pi 提示文字的语言回归覆盖。
- 更新检查失败时显示实际错误原因，便于定位网络、更新源或签名问题。

上游新增的 Images generations/edits 路由、takeover 登录态联动、并行工具默认值、额外模型定价与九月整组调价、SoleAPI 等本次尚未纳入，将单独验证。全部 54 个提交的处置见[逐项同步台账](../upstream-sync-v3.22.0.md)。本版属于选择性增量同步。

## 现有配置

保留 AI Coding 的暖橙主题、Dock、Bincode 应用、跨工具记忆同步、会话置顶/归档/导出及实时同步。新增预设供新建供应商时选择，不自动覆盖现有供应商卡、账号或用户自定义价格。继续使用 AI Coding 的应用身份、数据目录与更新源。本次新增预设不引入推广徽章和返利参数；既有预设中的 UTM 追踪链接保持原样。
