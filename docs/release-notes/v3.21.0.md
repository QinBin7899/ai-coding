# AI Coding v3.21.0

在 AI Coding 3.17.2 的基础上合并了上游 cc-switch 3.16.3 → 3.20.1 的全部更新。

## 新增（来自上游）

- 两个新应用：**Grok Build**、**Pi**（默认隐藏，设置 → 应用可见性里打开即可进 Dock）。
- **项目快照 Project Profiles**：一键切换整套供应商 / MCP / Skills / 记忆文件。
- Codex：第三方供应商切换改为只写 `config.toml`（兼容 Codex CLI 0.149），Auth Center 支持多个 ChatGPT 账号，官方账号退出自动故障转移。
- 用量看板：自动 / 手动扫描开关、字节游标增量扫描（大会话文件从秒级降到毫秒级）、models.dev 定价自动同步。
- Claude Code 托管 WebSearch 与 Codex Alpha Search 可走本地代理；模型选择器模糊搜索；大量预设与代理修复。
- 数据库 schema v11 → v18，首次启动自动迁移，迁移前自动备份到 `~/.zhongguoai/backups/`。

## 修复（合并期间发现）

- 「复用外部代理实例」的探测不再放在 `is_running()` 里发 HTTP 请求，而是缓存 `start()` / 状态轮询的探测结果；此前它与上游新的 Live 同步路径（同步上下文里 `block_on(is_running())`）组合会死锁。
- 启动时若上次使用的是默认隐藏的应用（Grok Build / Pi），不再在设置加载前被踢回 Claude。

## 保持不变

- 品牌、暖橙主题、底部 Dock、bincode 应用、跨工具记忆同步、会话置顶 / 归档 / 导出、会话实时同步与全文搜索。
- 数据目录 `~/.zhongguoai`、数据库 `ai-coding.db`、日志 `zhongguoai.log`、`~/.ai-coding/settings.json` 回退、WebDAV/S3 远端目录 `ai-coding-sync`、深链接 `aicoding://`、更新源。
- 不带上游的返利链接与合作伙伴徽章。

## 升级前必读

1. 升级后数据库变为 v18，**旧版 AI Coding 打不开**；应用会自动备份，仍建议先手动复制一份 `~/.zhongguoai`。
2. 已有的 Codex OAuth 账号会进入隔离态，请在 Auth Center 对每个账号点「重新登录」（不要用「添加账号」）。
3. 切换到第三方 Codex 供应商时默认会删除 `~/.codex/auth.json` 里的官方登录；想保留请先在设置里打开「切换时保留官方登录」。Codex CLI 请升级到 0.149+。
4. 若 `~/.codex/config.toml` 里还有旧的 `model_catalog_json = "cc-switch-model-catalog.json"`，请改成 `ai-coding-model-catalog.json` 或删掉该行。
