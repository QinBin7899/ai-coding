# AI Coding v3.16.2

This release focuses on turning AI Coding into a cleaner, branded, open-source desktop app for switching AI coding providers across domestic and international models.

## Highlights

- Renamed and rebranded the app as **AI Coding**.
- Added Bincode as an OpenCode-compatible managed app.
- Refined the warm orange visual system and dark default theme.
- Added a floating macOS-style Dock with dynamic hover magnification.
- Added cross-tool memory sync from Claude Code memory into other coding tools.
- Added Markdown export for local session records.
- Reworked the provider picker into domestic, custom, and overseas sections.
- Cleaned the public documentation so it only presents AI Coding branding, screenshots, and product features.

## Open Source Build

The public repository is intended to be usable as an open-source project. The open-source build should not require a commercial activation code.
