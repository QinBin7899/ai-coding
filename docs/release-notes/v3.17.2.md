# AI Coding v3.17.2

会话管理的两个体验修复。

## 修复

- **终端新消息实时同步**：在终端里用 Claude Code / Codex 聊天时，会话管理页会自动跟着更新。后端用 `notify` 监听 `~/.claude/projects` 与 Codex 的 `sessions` / `archived_sessions` 目录（递归，400ms 防抖），推送 `session-manager://changed` 事件；前端收到后刷新列表，若变化的是当前打开的会话则同时重载消息并保持滚动位置。另有每 3 秒一次的 mtime / size 轻量兜底轮询，即使监听不可用也能在 3 秒内更新。
- **搜索能搜到聊天内容**：原来只索引标题 / 摘要 / 目录，现在输入关键词 300ms 后会对当前会话集合做正文检索（后端按 mtime 缓存正文，只解析变化过的文件），命中的会话追加到列表并显示高亮片段。中英文均支持，大小写不敏感。
- **刷新按钮**同时刷新列表与当前会话内容。

## 说明

- 不改动任何环境变量、配置文件与现有布局；新增 Tauri 命令 `get_session_file_stat`、`search_session_contents`，新增 Rust 依赖 `notify = "8"`。
- 会话根目录不存在（对应 CLI 未安装）时静默跳过，并在后台每 30 秒重试挂载。
