# AI Coding v3.22.1

Windows 64 位安装包首次加入本仓库的 GitHub Release，与 macOS Apple Silicon 版一起提供下载。

## 下载与安装

- **Windows EXE**：`AI-Coding-v3.22.1-windows-x64-setup.exe`，日常安装推荐，支持简体中文和英文。
- **Windows MSI**：`AI-Coding-v3.22.1-windows-x64.msi`，Windows Installer 格式。
- **macOS Apple Silicon**：`AI-Coding-v3.22.1-macOS-aarch64.dmg`。
- 校验文件：`WINDOWS-SHA256SUMS`、`MACOS-SHA256SUMS`。

Windows 面向 Windows 10/11 x64，安装到当前用户目录。程序需要 Microsoft Edge WebView2；安装包内含引导安装程序，缺少运行环境时可能需要联网下载。当前 Windows 包未使用商业代码签名证书，系统可能显示“未知发布者”或 SmartScreen 提示。macOS 包采用本地签名，尚未通过 Apple 公证。

## 本次改动

- 提供 Windows EXE 和 MSI 两种安装包，使用 Windows 原生标题栏。
- 修复 Windows 调用 CLI 时，包含中文、空格及系统规范化路径前缀的 `.cmd` 文件无法正常执行的问题。
- 修复 Windows 旧 HOME 路径下数据库的识别，继续读取已有的 `ai-coding.db`。
- 修正 MSI 卸载范围，避免清理上级 Programs 目录中的其他文件。
- 保留 3.22.0 的会话精准/模糊搜索修复、完整聊天内容搜索及 AI Coding 定制功能。Windows 恢复会话通过复制命令后在终端执行，需要先安装相应 CLI。

## 发布验证

Windows 发布流程运行前端类型检查、格式检查、单元测试和生产构建，以及 Windows Rust 编译检查、Clippy 和测试。随后核验 x64 程序及安装包版本，在临时 Windows 构建机上静默安装 MSI、观察程序启动 15 秒、卸载，并检查无关文件与测试数据哨兵是否保留。所有检查通过后才上传发布。

`WINDOWS-VALIDATION.json` 随安装包提供，记录对应源码提交和安装验证结果。启动检查验证进程存活；它不等同于在 Windows 10/11 实机上逐项人工操作所有界面。

此版本的 macOS 核心功能与 3.22.0 一致，使用相同版本号重新构建。此前的安装包和版本标签保留。
