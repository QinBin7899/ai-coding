# AI Coding v3.17.1

A small bugfix release following v3.17.0.

## Fixes

- **No more empty "default" provider**: on startup, AI Coding imports your current live CLI config as a provider entry so switching presets never loses it. When that live config was effectively empty (for example a Claude `settings.json` containing just `{}`), the import still created a useless "default" entry and marked it as the current provider. Empty snapshots are now skipped entirely.
- **Test suite repairs**: the Rust integration tests had been failing since the project rebrand because they referenced old storage paths and names. Test isolation and path expectations were fixed; the full suite now passes.

## Notes

- If your provider list already shows an empty "default" entry from an earlier version, you can safely delete it in the app. Entries named "default" that contain your real configuration (for example an imported ChatGPT login or API key) are unaffected and should be kept.
