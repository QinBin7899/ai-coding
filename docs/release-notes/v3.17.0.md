# AI Coding v3.17.0

This release adds chat organization tools to the session manager and fixes the macOS "damaged app" issue reported by downloaders.

## Highlights

- **Chat archive**: the session list now has a second "Archived" tab. Move finished or noisy sessions there to keep the main list focused on active work.
- **Session pinning**: pin important sessions and they stay at the top of the list in a dedicated "Pinned" group, so project sessions are easy to find again.
- Pin and archive actions appear when hovering a session in the list; state is stored locally and survives restarts.

## Fixes

- macOS release builds are now fully ad-hoc signed. Previous builds only carried a linker signature, which made Gatekeeper reject downloaded copies with a "damaged and can't be opened" error.
- The README now documents first-launch steps for macOS: use **System Settings → Privacy & Security → Open Anyway**, or run `xattr -cr "/Applications/AI Coding.app"` once.
