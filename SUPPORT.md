# Support

AI Coding is an open-source desktop tool for managing AI coding providers, routes, memories, skills, MCP servers, prompts, sessions, and exports.

## Before Opening an Issue

- Check the README for setup and feature notes.
- Search existing issues to avoid duplicates.
- Include screenshots, logs, and your operating system when reporting a problem.

## Where to Ask

- Bug reports: https://github.com/QinBin7899/ai-coding/issues/new?template=bug_report.yml
- Feature requests: https://github.com/QinBin7899/ai-coding/issues/new?template=feature_request.yml
- Documentation fixes: https://github.com/QinBin7899/ai-coding/issues/new?template=doc_issue.yml
- General questions: https://github.com/QinBin7899/ai-coding/issues/new?template=question.yml

Please do not post secrets, API keys, activation codes, or private provider credentials in public issues.
